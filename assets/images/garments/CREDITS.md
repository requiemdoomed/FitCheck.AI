# Garment photos

The clothing photos in this folder are real photos from the **Clothing dataset
(subset)** by Alexey Grigorev and contributors,
https://github.com/alexeygrigorev/clothing-dataset-small, released under
**CC0 1.0 Universal** (public domain dedication). Each photo was cropped to 4:5,
resized to 480×600 and lightly colour-corrected for FitCheck.AI.

`catalog.json` lists every photo with the source file it came from, plus the
names, colours and tags FitCheck.AI uses for it (the landing-page outfit mixer
and the in-browser demo loader, `assets/js/local/backend.js`, both read it).

Photos showing brand logos were deliberately left out.
